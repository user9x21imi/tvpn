Запуск: `vpn` или `VPN`. Панель работает от deck, сетевой backend — от root.
Полноэкранный Konsole: Ctrl+Shift+F. Для 1280×800 подходит моноширинный шрифт
10–12 pt. На узком экране карта переносится над показателями; все показатели
умещаются при 80×32 и 65×35 символах.

- **R / кнопка «Регион»** — список локаций; ↑/↓ или J/K — выбор,
  Enter — переключение, Esc — отмена. Можно щёлкнуть по кнопке и строке мышью.
- **L** — журнал текущего запуска; после ошибки **Q/Enter** закрывает панель.
- **Ctrl+S** — остановить туннель, оставить панель с крупным точечным STOPED; повторное Ctrl+S подключает заново. Ctrl+C также останавливает без закрытия панели.
- Точка @ — город из настройки шлюза. Выбранная страна на карте жёлтая;
  после HTTPS-проверки через riseupvpn0 и совпадения страны — зелёная.
  До этой проверки внешний IP и подтверждённый регион не отображаются.

Доступен выбор шести локаций Riseup: Амстердам (NL), Париж (FR), Монреаль (CA),
Нью-Йорк, Майами и Сиэтл (US). Актуальные публичные шлюзы выбранного города
загружаются с https://api.black.riseup.net/3/config/eip-service.json с проверкой
TLS. Используются только объявленные OpenVPN-транспорты, адреса и порты;
пригласительные и ограниченные шлюзы отбрасываются. При неудаче пробуются
остальные шлюзы того же города. Если каталог не отвечает, только Амстердам
может использовать два исходных сохранённых адреса. Для остальных регионов
показывается ошибка; наличие пункта в меню не означает проверенную доступность.
При смене региона новый backend запускается только после завершения старого
и подтверждения cleanup. Сертификат запрашивается заново.

Карта строится офлайн из настоящих контуров Natural Earth 1:110m (177 стран),
с проекцией долготы/широты и растеризацией в символы Unicode Braille 2×4 точки.
Подсветка соответствует стране выбранного города, а не всему континенту.
Координаты города — конфигурация, не измеренная геолокация внешнего IP.
Источник карты и условия использования — SOURCES.md.

Скорость: разность rx_bytes/tx_bytes из /sys/class/net/riseupvpn0/statistics
за фактически прошедшее монотонное время. МиБ = 1024² байт, ГиБ = 1024³ байт.
Суммарный объём — с первого замера текущего туннеля; смена шлюза,
исчезновение интерфейса и сброс счётчиков начинают замер заново.
Графики показывают до 60 секунд и масштабируются по своему пику;
в узком окне соседние секунды объединяются с отображением максимума.
Журнал ограничен 120 строками в памяти. PEM-блоки и управляющие символы
фильтруются; панель не читает client.pem и client.ovpn.

Однократно выполните в терминале Linux:

```sh
bash "$HOME/.local/share/riseup-vpn/install-passwordless.sh"
```

Только эта административная установка запрашивает пароль sudo. После неё
`vpn`, `VPN`, смена регионов и текстовая диагностика работают без пароля
через `sudo -n`. Без установленного правила запуск VPN останавливается
с инструкцией и не запрашивает пароль автоматически.

Установщик копирует backend и нормализатор каталога в `/var/lib/riseup-vpn`
с владельцем root. В `/etc/sudoers.d/zz-riseup-vpn` разрешаются только 13
точных вариантов запуска этого backend: шесть фиксированных регионов,
с событиями панели или без них. Редактируемая пользователем копия .sh
не получает беспарольный доступ к root. Конфигурация проверяется visudo.
Обновив .sh или riseup_regions.py, повторите установку для обновления
защищённой копии. Установка не меняет пароль deck и остальные правила sudo.
Для удаления разрешения администратор может удалить
`/etc/sudoers.d/zz-riseup-vpn` и `/var/lib/riseup-vpn` после остановки VPN.

Распакуйте архив, откройте Konsole в папке RiseupVPN-Panel и выполните:

```sh
mkdir -p "$HOME/.local/share/riseup-vpn"
```text

```
cp -p "$HOME/.local/share/riseup-vpn/Riseup-Amsterdam-SteamDeck.sh" \
  "$HOME/.local/share/riseup-vpn/Riseup-Amsterdam-SteamDeck.sh.backup"

Если файла ещё нет, пропустите cp. В ~/.zshrc должны быть алиасы
(если они ещё не настроены):

```sh
alias vpn='bash "$HOME/.local/share/riseup-vpn/Riseup-Amsterdam-SteamDeck.sh"'
alias VPN='bash "$HOME/.local/share/riseup-vpn/Riseup-Amsterdam-SteamDeck.sh"'
```

Откройте новую вкладку и выполните `vpn`. Можно сразу выбрать город:
`vpn --region paris`. Текстовая диагностика: `vpn --text --region seattle`.
Идентификаторы: amsterdam, paris, montreal, newyork, miami, seattle.
Получение каталога и сертификата отдельно показывают адрес, порт и лимит
12 секунд на попытку. Каждый этап может занять до четырёх попыток (~48 с).

Копии до изменений: `Riseup-Amsterdam-SteamDeck.sh.before-panel`,
`Riseup-Amsterdam-SteamDeck.sh.before-regions`, `riseup-panel.py.before-regions`.

36 тестов: тайм-аут сертификата; разбор и отказ каталога; резервные шлюзы;
шесть регионов; отказ при несовпадении страны; расчёт и сброс трафика;
штатный DNS-hook из встроенного архива на временном resolv.conf;
карта и компоновка; PTY-запуск, журнал, resize и Ctrl+C; смена региона
только после cleanup и отказ при его отсутствии; sudo -n и проверка
13 точных правил visudo. Сетевые процессы в тестах подменены.
Встроенный runtime OpenVPN сохранён побайтно.

Автоматические проверки выполняются без создания реального VPN-туннеля.
Нативную установку и подключение на macOS нужно подтвердить на Mac.
В Linux перед запуском сохраните `ip -4 route`, `ip -6 route`,
`cat /etc/resolv.conf` и, при systemd-resolved, `resolvectl status`.
После Ctrl+S сравните состояние с исходным и убедитесь, что
`ip link show riseupvpn0` больше не находит интерфейс.

Обновление macOS: один вход — `Install-RiseupVPN.command` (или
`start-macos.command` в скачанной папке). Шрифты: `U` — ASCII/Unicode.
Город шлюза и город GeoIP показываются отдельно; недоступные регионы
не подключаются. Открывайте [README.md](README.md) для актуальной установки.
